# RUNLAB decisions

| # | Decision | Why |
|---|---|---|
| D1 | Keep the classic-script, no-build architecture; new code under `public/js/lab/` (pure modules + one view module). | Directive; no measured limitation requires a framework. |
| D2 | Lab records are a private sync collection `lab/{id}` with strict rules payload checks; denied `lab` reads never break sync on older rules. | Additive, account-isolated, same conflict handling as runs. |
| D3 | Analyses are pure, versioned (`weekly-1`, `trend-1`, `compare-1`, `quality-1`) and return one typed shape. Snapshots store exact record ids (≤400), method version and an `answersKey`; changing answers makes a snapshot stale instead of silently reusing it. | Reproducibility and "recompute vs saved snapshot" honesty. |
| D4 | Pace analyses use only runs with recorded duration; implausible paces (outside 2:30–20:00 /km) are flagged and excluded, never corrected. Minimum 3 runs per group/half, else "Belum cukup data". | No estimated evidence; avoid single-sample claims. |
| D5 | Time-of-day comparison only uses imported start times (`extId t:…`); manual runs are excluded with the reason "jam mulai tidak tercatat". Heat questions get no analysis because temperature is not measured (weather is free text). | Never infer missing variables. |
| D6 | Research uses PubMed E-utilities + OpenAlex directly from the browser (both are reported to allow CORS; **unverified from the sandbox**). OpenAlex is called keyless (small per-IP daily budget, 429 "Insufficient budget" shown plainly); a key may only ever live in a server proxy; results are filtered for running relevance, deduplicated by DOI → PMID, cached 14 days locally, and only provider fields are stored. | No server or billing needed for M3. Live calls were **not verifiable** from the build sandbox (host access declined); tested with real-shaped mocks. |
| D7 | No `email`/`mailto` sent to NCBI/OpenAlex (only `tool=werunit`). | Never send the user's email to third parties; NCBI recommends but does not require it at low volume; OpenAlex ignores `mailto` since 2026. |
| D8 | AI consultation stays **not configured**: capability chip says so; no mock output anywhere. A provider-neutral contract is documented for a future server-side adapter. | Directive; no key, no budget, no server authorized. |
| D9 | Glass: only the nav/segmented spring pill (owner's motion spec). Everything else solid; gradients only in the Lab hero trace lane. | Resolve DESIGN.md vs CSS contradiction truthfully. |
| D10 | The 4.0 auto "headline/sub/Detail" paragraph splitter skips the Lab (`.lab2`). | Lab text is already structured; the splitter produced odd "Detail" folds. |
| D11 | Strava-origin runs stay usable for on-device calculations but are flagged and will be excluded from any AI payload. | Strava terms prohibit AI use; local deterministic math on the user's own export is not an AI use. |
| D12 | Findings carry an **evidence grade** computed by `WRI_ANALYSIS.grade()` without changing any metric: *Deskriptif* (counts/coverage), *Bukti belum cukup* (below the minimum n), *Observasi* (a difference exists but is not supported), *Didukung uji statistik* (two-sided permutation test on the difference of medians, 4000 shuffles with a data-derived fixed seed, p < 0.05, ≥ 6 runs per group, |difference| ≥ 5 s/km). Wording always says association, not causation. | The directive asks to distinguish observations, insufficient evidence and supported findings. A permutation test makes no distribution assumption and is reproducible. No formula was altered. |
| D13 | Each finding shows **metric n vs eligible records** ("n 15 (8 + 7) dipakai di analisis ini dari 33 lari yang memenuhi syarat") plus the exclusion reasons. For trend, the comparison band is named. | The old "33 lari masuk analisis" read as if every analysis used 33 runs. |
| D14 | The focal finding is chosen by a fixed order (compare → trend → weekly → quality); for trend the band with the most runs in its smaller half leads. | Deterministic and question-relevant; data quality is supporting context. |
| D15 | Feedback is a compact snackbar (`toast(msg, kind)`, kinds ok/err/info, error stays 4.2 s with `role="alert"`); the floating record button is hidden on the Lab tab. | The large centred pill covered content; the FAB overlapped charts and coverage rows. |
